- Learning exchange requests
- Messaging and scheduling

## 4. Follow-up after signup

Thanks for joining the SkillBarter beta.

Please complete these steps:
1. Add one skill you can teach.
2. Add one skill you want to learn.
3. Open **My Learning Matches**.
4. Send a request to a relevant person if one is available.
5. Try completing an exchange.

If you don't find a match, that's useful feedback too — don't create a fake match. Try another skill, widen your radius, or invite a classmate.

## 5. Feedback request

Thanks for testing SkillBarter.

After trying it, please tell me:
- What were you trying to learn?
- Did you find a relevant person?
- What was confusing?
- What stopped you from sending or accepting a request?
- Did the exchange feel clear and safe?
- What is the one thing you would change?

Use the in-app **Beta Feedback** page where possible.

## Outreach tracking

For campaign links, use UTM parameters so acquisition can be measured:

`utm_source` — platform, e.g. whatsapp, linkedin, college_group

`utm_medium` — channel, e.g. dm, post, group

`utm_campaign` — campaign name, e.g. beta-september

`utm_content` — message/creative variant

Example pattern:

`[PRODUCTION_URL]/?utm_source=whatsapp&utm_medium=group&utm_campaign=beta-september`

Do not put passwords, OTPs, private addresses, or other sensitive information into outreach links or messages.
